# Corrected bridge packages

The prepared Pi serves verified x86_64 and ARM64 bridge packages. Normal users run the recorder manual's installer; no build is required. This catalog records package hashes, the pinned upstream source and the duplication correction. Matching archives are attached to the release and include upstream license/build information. The maintainer installs them under the Pi's `robot-recorder/dist/bridge-packages/` directory. Humble and Jazzy are supported by the installer; a full new Orin/Humble acceptance run remains pending.
