# 机器人数据记录器

[English](README.md) | **简体中文**

用于机器人实验的 ROS 2 数据记录器。机器人通过以太网和 Zenoh 将话题传到树莓派；用户在局域网浏览器中选择话题并控制录制，MCAP 文件保存在树莓派。

## 主要功能

- 发现并选择 ROS 2 话题，开始/停止录制，按大小或时长切分 MCAP。
- 查看录制大小、时长、各话题消息数及平均 Hz，下载或删除录制。
- 显示空间、温度、机器人连接状态和简短录制警告。
- 可选 MinIO 上传：先做带索引的 Zstandard 无损压缩，支持手动/空闲自动上传、停止/恢复及上传校验；录制始终优先。

## 首次使用

先看 [记录器使用手册](docs/user-manual.zh-CN.md)（[English](docs/user-manual.md)），按正常流程操作；遇到异常再看排查部分：

1. 将已配置的树莓派、路由器 LAN 口及机器人连接到同一交换机。
2. 启动机器人的正常 ROS 发布器，并加载平时使用的工作空间。
3. 运行一次安装命令：下载预编译桥，自动选择 ROS 环境，启用开机服务并集中检查连接。
4. 从 **Robot Recorder** 应用入口或浏览器打开配套树莓派的保留有线地址 `http://192.168.1.182:8080`，选择话题并录制；结束后查看、下载或删除。

树莓派由维护者预先配置。机器人需已有 ROS 2 Humble 或 Jazzy。桥包从树莓派获取，缺少的 ROS 依赖需要互联网。用户无需克隆仓库或手动构建；日常本地录制不依赖互联网。

## 日常使用

给套装和机器人通电，启动机器人的发布器，然后在接入交换机的电脑打开 **http://192.168.1.182:8080**。机器人桥自动启动，树莓派晚些可用时也会重新连接，无需保留桥终端。仅打开网页的电脑不需要安装 ROS 或 Zenoh。

停止后等待收尾，再查看结果。套装地址改变或机器人保留其他网段的固定以太网地址时，按手册排查；本地名称地址仅作为可选快捷方式。

## 可选增强：LoRa 远程控制

需要远距离操作时，使用配套 USB LoRa 电台及操作笔记本，按 [LoRa 说明](docs/lora-remote.zh-CN.md)（[English](docs/lora-remote.md)）安装。它提供话题选择、开始/停止、状态和简要录制管理；传感器数据仍走机器人到树莓派的以太网/Zenoh。

LoRa 控制端可离线安装，使用时无需树莓派 IP 或现场网络。GitHub 下载需互联网，首次配对口令由维护者私下提供。安装后从 **Robot Recorder LoRa** 应用入口启动后台控制端，无需保留终端；再次打开会复用已有实例。默认收到状态回复后等待一秒再请求；LoRa 页面不下载 bag。

## 仓库内容

本仓库提供说明书、机器人桥安装工具，以及可选 LoRa 客户端源码和 [安装器](https://github.com/FCosx/recorder-lora-remote/releases/latest)。树莓派录制服务由维护者单独准备。公开配对文件已加密，树莓派密码及解密后的配对文件不公开。

机器人桥同时启动轻量带宽助手。刷新任一 UI 会在机器人端短暂采样；开始录制前必须关闭临时订阅。旧机器人可在记录器空闲时重跑手册安装命令，更新助手和自动启动设置。

LoRa 安装包含 pySerial 3.5，许可见 [第三方说明](THIRD_PARTY_NOTICES.md)。
